재난문자 긴급도 자동 분류 시스템 — 발표 내용 정리
================================================================================

■ 프로젝트 개요
-------------------------------------------------------------------------------
과제명  : 한국 재난문자(CBS) 5단계 긴급도 자동 분류
목표    : 재난문자를 L0(긴급아님) ~ L4(매우높음) 5단계로 딥러닝 분류
데이터  : 공공데이터포털 재난문자 + 수동 레이블링 → dedup_v7 (136,987건)
모델    : KoELECTRA v3 기반 5-class classifier (v22, 완성)

최종 목표 (전부 달성):
  - MacroF1 ≥ 98%  →  달성: 98.75%
  - L4 Precision ≥ 95%  →  달성: 96.9%
  - Accuracy ≥ 98%  →  달성: 99.27%


■ 1. 레이블 정의
-------------------------------------------------------------------------------
레이블  이름        정의
L0      긴급아님    행동 불필요 (해제, 종료, 예방 안내, 훈련)
L1      낮음        주의 권고 (예보 수준, 잠재적 위험)
L2      중간        행정 조치 / 방역 협조 (상황 발생, 시설 대응)
L3      높음        야외 자제 / 예방적 조치 (재난 진행 중)
L4      매우높음    즉각 대피 명령 (생명 위협, 지금 당장)

핵심 원칙:
  "경보" 있어도 해제 공지이면 L0
  "대피" 없어도 즉각 위험이면 L4
  → 레이블은 특정 키워드 유무가 아닌 상황 심각성 + 행동 즉시성으로 결정


■ 2. 데이터셋 구성 (dedup_v7)
-------------------------------------------------------------------------------
항목            건수        비율
Train           95,890      70%
Validation      20,548      15%
Test            20,549      15%
합계            136,987     100%

주요 처리:
1) COVID 편향 제거
   - 2021년 이후 L0 COVID 문자 70% 제거
   - 이유: 모델이 "COVID = L0" 으로 암기 → 신종 감염병 분류 오류 방지
2) 합성 데이터 추가 (총 100건 → upsample 5배 → 305건)
   - COVID 키워드 없는 합성 L1 50건 + L2 50건
   - 이유: OOD 신종 감염병 케이스 일반화


■ 3. 모델 아키텍처
-------------------------------------------------------------------------------
베이스 모델: monologg/koelectra-base-v3-discriminator (KoELECTRA v3, ~110M params)
출력: 5-class softmax classifier

[핵심 기법 3가지]

① 키워드 마스킹 증강
  - 학습 시 긴급도 관련 키워드 26개를 ' '(공백)으로 치환
  - "즉시 대피", "경보", "주의보", "대피명령" 등
  - 목적: 키워드 없이도 문맥만으로 분류할 수 있도록 강제
  - 검증 방법: 마스킹 F1 (키워드 제거 후 평가)

② 3-Component 손실 함수
  L_total = CE(원본) + α_masked × CE(마스킹) + α_kl × KL(p_원본 ∥ p_마스킹)
  - CE(원본): 원본 텍스트 FocalLoss (γ=2.0)
  - CE(마스킹): 마스킹 텍스트 FocalLoss → 키워드 없는 맥락 학습
  - KL Divergence: 원본-마스킹 예측 분포 일치 → 일관성 강제

③ Ordinal Label Smoothing (v22 핵심 기법)
  - 문제: v21에서 L3↔L4 경계 혼란 → L4 Precision 89.9%
  - 원인: 표준 Label Smoothing이 smoothing mass를 모든 클래스에 균등 배분
  - 해결: 인접 클래스에만 smoothing mass 배분

  예: L4에 대한 soft label (α=0.1)
    표준  :  [0.02, 0.02, 0.02, 0.02, 0.92]  ← 원거리 클래스에도 배분
    Ordinal: [0.00, 0.00, 0.00, 0.10, 0.90]  ← L3에만 배분
  → L3과 L4 간 경계를 명시적으로 순서형으로 학습


■ 4. 개발 과정 요약
-------------------------------------------------------------------------------
단계 1 : 3-class 분류 (긴급/주의/일반) → MacroF1 96.58%
단계 2 : 5-class 전환 — KLUE-BERT → MacroF1 99.43%, 마스킹 97.5%
단계 3 : KoELECTRA 전환, FocalLoss, WeightedSampler → 마스킹 97.3%
단계 4 : 3-component 손실 도입 → 토크나이저 오류로 무효 (v9~v9d)
단계 5 : 3-component 손실 정상 작동 → 마스킹 97.5%대 정체
단계 6 : [돌파구] 레이블링 기준 문서화 + 데이터 재레이블 (v9n) → 마스킹 98.75%
         → v9m(97.55%) 대비 +1.2%p — 아키텍처가 아닌 데이터 품질의 효과
단계 7 : L3 임계값 후처리 → 목표 잠정 달성 (MacroF1 98.83%)
단계 8 : OOD 개선 실험 (v14~v17) — dedup_v6 + 감염병 합성 500건 추가
         → L4 Precision 87~89%대 하락, 목표 미달성
단계 9 : 전략 전환 — dedup_v7 재구성 + 처음부터 전체 재학습 (v19~v21)
         → v21 MacroF1 95.86%, L4 Precision 89.9% (L3↔L4 경계 혼란)
단계 10: Ordinal Label Smoothing + LR 최적화 (v22) → 목표 전부 달성 ✅
단계 11: KNN OOD + 3단계 파이프라인 구축 → 신종 재난 탐지 시스템 완성

■ 8. 3단계 추론 파이프라인
-------------------------------------------------------------------------------
입력 재난문자
     │
     ▼
[1단계] KNN OOD 탐지
  KNN cosine 거리 > p99 threshold?
     │YES → "OOD 거부" (신종 재난 / 비재난)
     │NO
     ▼
[2단계] Confidence Threshold (85%)
  softmax 최댓값 < 0.85?
     │YES → LLM fallback (판단 유보)
     │NO
     ▼
[3단계] v22 분류
     → L0 / L1 / L2 / L3 / L4 출력

KNN 파라미터: K=20, cosine distance, brute force

  L0: 0.018056
  L1: 0.015686
  L2: 0.014583
  L3: 0.007599

■ 10. 핵심 인사이트 및 결론
-------------------------------------------------------------------------------
1) 레이블 품질이 가장 중요 (단계 6 교훈)
   - 코드/아키텍처 개선 7번 → 마스킹 F1 97.5% 정체
   - 레이블링 기준 문서화 + 재레이블 1번 → +1.2%p 급등
   - "쓰레기 넣으면 쓰레기 나온다 (Garbage In, Garbage Out)"

2) 데이터 편향 제거가 성능과 일반화 모두에 기여 (단계 9 교훈)
   - COVID L0 70% 제거 → COVID 암기 편향 완화
   - dedup_v7 균형 데이터로 처음부터 재학습 → 더 견고한 모델

3) 순서형 구조 활용이 경계 케이스 성능을 개선 (단계 10 교훈)
   - Ordinal Label Smoothing: L3↔L4 Precision 89.9% → 96.9%
   - 표준 smoothing vs ordinal smoothing의 차이를 실험으로 검증

4) KNN OOD는 신종 재난 탐지의 실용적 해법
   - 20케이스 중 7건(35%) OOD 탐지 — 재학습 없이 배포 후 안전망 역할
   - 완벽하지 않지만 confidence threshold와 결합 시 3단계 안전 파이프라인 구성 가능

5) 최종 모델 사양
   - 모델: model_v22 (KoELECTRA v3 기반)
   - 토크나이저: tokenizer_v22 (vocab 35,000)
   - 파이프라인: 실험/predict_full_pipeline.py
   - Accuracy: 99.27%, MacroF1: 98.75%, L4 Precision: 96.9%
