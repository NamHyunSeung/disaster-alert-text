# 재난문자 레이블 기준 (맥락 기반 / 키워드 독립)

## 핵심 원칙
- **키워드 무시**: "대피", "경보", "주의보", "특보", "화재", "홍수" 등 긴급도 표현 키워드는 레이블 판단에 사용하지 않는다.
- **상황 심각도**: 문장이 설명하는 실제 상황의 객관적 위험 수준으로 판단한다.
- **요구 행동의 즉시성**: 문장이 수신자에게 요구하는 행동의 긴급성/즉시성으로 판단한다.
- **마스킹 후 판별 가능성**: 긴급 키워드를 제거한 후에도 남은 맥락만으로 레이블이 결정되어야 한다.

---

## 레이블 정의

### L0 — 긴급아님
- **기준**: 비상 상황 없음. 일반 행정 공지, 훈련 안내, 완료/해제 알림, 행사 정보
- **행동 요구**: 없음. 참고용 정보 제공.
- **예시 패턴**:
  - "○○ 훈련이 실시됩니다. 참고하시기 바랍니다."
  - "○○이 해제되었습니다."
  - "○○ 행사를 안내드립니다."

### L1 — 낮음
- **기준**: 잠재적 위험 언급 수준. 별도 행동이 불필요한 정보성 권고. 상황이 발생할 수도 있다는 예보 수준.
- **행동 요구**: 없거나 매우 경미 (관심 가져달라, 확인 바란다 수준)
- **예시 패턴**:
  - "○○이 예상됩니다. 주의 바랍니다." (예보 수준)
  - 단순 정보 전달형 안내

### L2 — 중간
- **기준**: 특정 상황이 현재 발생했거나 행정 조치가 시행됨. 일상에 영향을 주지만 즉각적 생명 위험 없음.
- **행동 요구**: 행정 조치 준수 (집합금지, 시설 폐쇄, 출입 제한, 방역 협조), 감염병 관련 조치
- **예시 패턴**:
  - "○○ 확진자 발생으로 해당 시설 폐쇄, 방역 중입니다."
  - "○○인 이상 집합금지, 마스크 착용 철저히 해주세요."
  - "○○ 지역 출입을 금지합니다." (안전상 이유가 아닌 행정 조치)
  - "○○로 인해 수업/운영 중단됩니다."

### L3 — 높음
- **기준**: 기상·재난 상황이 현재 진행 중이며 상당한 행동 변화가 필요. 관련 분야(농작물, 시설, 건강)에 피해 가능성 있음.
- **행동 요구**: 야외 활동 자제, 수분 섭취/체온 유지, 시설물 점검, 수도 동파 대비, 농작물 피해 대비 등 예방적 조치
- **예시 패턴**:
  - "현재 강풍이 불고 있어 야외 활동을 자제하시고 시설물을 점검하세요."
  - "무더위가 지속되어 야외 작업을 자제하고 수분 섭취를 권장합니다."
  - "한파가 예보되어 수도 동파 및 농작물 피해 대비가 필요합니다."
  - "폭설이 내려 도로 결빙에 주의하시고 대중교통을 이용하세요."

### L4 — 매우높음
- **기준**: 즉각적인 안전 행동 필요. 특정 구역의 생명 위협, 즉각 이동/대피 지시, 접근 금지 지역 지정.
- **행동 요구**: 특정 장소로 이동, 특정 지역 즉시 벗어나기, 위험 구역 접근 절대 금지 (생명 안전 이유)
- **예시 패턴**:
  - "하천 범람으로 인근 주민은 마을회관으로 즉시 이동하시기 바랍니다."
  - "산사태 위험이 있어 해당 구역 주민은 안전한 곳으로 이동하세요."
  - "현재 위험 상황이 진행 중이므로 해당 구역에 절대 접근하지 마세요."
  - "국가 위기 수준의 상황이 발생하여 즉각적인 안전 조치가 필요합니다."

## 경계 케이스 판단 기준

| 상황 | 판단 |
|------|------|
| 기상 경보 발효 + 야외 자제 권고 | **L3** (예방적 행동 요구) |
| 특정 구역 접근 금지 (안전) | **L4** (즉각 안전 조치) |
| 특정 장소로 이동 지시 | **L4** (즉각 대피) |
| 집합금지/영업제한 (방역) | **L2** (행정 조치) |
| 농작물/시설 피해 대비 | **L3** (예방적 준비) |
| 감염병 발생 + 방역 완료 알림 | **L2** (상황 발생 + 조치) |
| 훈련/연습 관련 | **L0** (비상 상황 없음) |

---

## 주요 변경 가능성이 높은 케이스

1. **L2 → L4**: 범람·산사태·화재 등으로 특정 장소 이동 지시가 있는 L2 샘플
2. **L4 → L3**: 경보 발령 + 일반 예방 조치만 요구하는 L4 샘플 (즉각 대피 없음)
3. **L3 → L2**: 공공시설 제한·집합금지 등 행정 조치 성격의 L3 샘플
